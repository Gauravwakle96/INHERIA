## Acceptance journey

An unauthenticated visitor can open Explore demo beside sign-in, understand the
ShopEase DevOps case study, and start an isolated, expiring workspace. Gaurav is
departing, Savinay receives ownership, and Rudransh coordinates the transition.
Every visitor's workspace is separate. Persona switching is limited to that
visitor's demonstration identities and never enables access to real accounts.

Connect authorised sources → reconstruct source-linked candidates → inspect
uncertainty/conflicts → independently review → generate the incoming user's
accessible continuation plan → accept/reject ownership → submit practical
evidence → supervisor assessment → close only after mandatory prerequisites.

Demonstrate the failure path too: an outdated runbook or rejected exercise
requires correction, investigation, a new version, reapproval and reassessment.
No example approval or test result is represented as a real company record.

## Delivery increments

1. Trust: decision authority resolution, accurate readiness and action states,
   complete ownership lists, understandable next actions.
2. Judge experience: public guide, isolated seeded workspace, scoped expiring
   persona sessions, source examples, role-specific journey and permission demo.
3. Secure onboarding: expiring single-use hashed invitations, own-password setup,
   revocation and audit; scoped access requests with independent decisions.
4. Transfer recovery: explicit reopen, version history, reapproval, mandatory
   prerequisites, named scenario criteria and affected task reassessment.
5. Investigation: supported prose extraction with exact evidence, change impact
   across claims/transitions/exercises and persisted resumable progress.
6. Quality: permission/failure/integration tests, desktop/mobile/day/night and
   keyboard checks, production build, dependency audit, deployment smoke checks,
   architecture/API/setup/limitations and truthful evaluation evidence.

## Deliberate limits

No production/cloud execution, cross-company learning, predictive accuracy
claims, voice/OCR, enterprise SSO/MFA or unrestricted external integration.

content is an authored case study, with uncertainty and human actions distinct.
Rubric targets guide acceptance checks; they are not an awarded score.
